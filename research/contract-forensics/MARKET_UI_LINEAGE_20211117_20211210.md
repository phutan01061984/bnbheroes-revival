# BNB HEROES Market UI lineage — 17 Nov target vs later build

Preservation target: frontend capture **2021-11-17 19:08:01 UTC**, aligned BSC block **12,730,607**.

## Exact 17-Nov frontend behavior

The 17-Nov Market component renders the page title `MARKETPLACE` followed by:

> Sorry. We are in maintenance mode for a while.

The build's Market ABI already contains `purchaseListing`, `cancelListing`, and `changeListingPrice`, but the 17-Nov Market page does not expose/call those write paths. The active marketplace write in the preserved frontend is the **Sell Hero** flow from My Heroes, which calls `addListing(tokenId, priceWei)` after BNBH and NFT approval.

Evidence artifact: `research/play_forensics/recovered/build-20211117/main.pretty.js`.

Relevant recovered-code areas:

- Sell modal / `addListing`: around lines 4200–4470.
- Market component / maintenance message: around lines 7420–7710.
- The production runtime `static/js/main.5e2ca500.chunk.js` also contains the maintenance message and does not contain active `.purchaseListing(` / `.cancelListing(` / `.changeListingPrice(` UI call sites.

## Later build behavior

A later recovered production-family bundle under `research/play_forensics/recovered/pretty/main.pretty.js` explicitly exposes:

- **Buy Hero** -> `purchaseListing(tokenId)`
- **Change Price** -> `changeListingPrice(tokenId, newPrice)`
- **Cancel Listing** -> `cancelListing(tokenId)`

These are visible around the recovered later-bundle sections near lines 7975–9752.

Therefore these controls are **version-later functionality** and must not be backported into the 17-Nov preservation target merely because the ABI already contains their selectors.

## Historical chain state vs UI state

The exact chain at block 12,730,607 still had **966 active Market listings** and `taxFee = 10`, preserved in:

`research/historical-world/MARKET_20211117_BLOCK12730607.json`

This is useful historical-world evidence, but it does not override the fact that the 17-Nov captured frontend intentionally put the marketplace browsing/purchase page in maintenance mode.

## Preservation decision

- Keep the exact 17-Nov Market page in maintenance mode.
- Keep the original My Heroes -> Sell -> `addListing` flow working through the local provider.
- Do not add later Buy/Cancel/Change controls to the target frontend.
- Retain the 966-listing snapshot as research/evidence for identity and economy reconstruction, not as justification to alter the target UI.
